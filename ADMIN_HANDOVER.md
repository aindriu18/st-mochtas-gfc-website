# Website administrator handover

This public repository intentionally uses placeholder identities and does not contain live administrator addresses, authentication values or recovery information.

## Club handover checklist

1. Give at least two current club officers access through the chosen identity provider.
2. Configure approved administrator addresses only in the hosted environment settings.
3. Keep recovery access under a club-controlled account.
4. Test sign-in, draft saving, publication, archive upload, archive review and sign-out.
5. Remove access promptly when an officer leaves their role.
6. Review administrator access at least once each year.

## Archive routine

Archive metadata is held in D1 and uploaded files are held in R2. Administrators should periodically export the archive register and retain approved original files in the club's own independent storage.

New uploads enter a private review queue. Check ownership, consent, safeguarding, titles and alternative text before publication. Do not publish changing-room images, private addresses, medical information or material without permission.

## Secrets

Never commit real environment values. Use the hosting provider's protected environment settings for administrator allowlists, authentication URLs, publishable keys and session secrets.
